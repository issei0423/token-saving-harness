# 持ち主がいないとき（詳細）

`graph.md` から切り出した（読む合図：「→ 読む：away.md」）

- 頭役が自分で回す合図と読む。「次を考える」で、依頼の範囲の外の仕事も作ってよい
- 終わる時刻と予算の線を、受けた時点で状態ファイルに書く
- **持ち主の答えを待って止まらない。** 持ち主にしか決められない枝だけを保留にし、ほかの点を進める。保留は報告の「持ち主にしか決められないこと」へ
- 点を出す前に `bash ~/.claude/token-harness/core/budget.sh 85 50` の「判断：」の行を見る。「契約の枠」「小さく」のときだけ点を出す（「小さく」なら同時2体まで、research・test を先に）。「待つ」なら新しい点を出さず、区切りで報告する
- 枠（同時4体）を空けたままにしない。係が終わったら、予算を見て次の点を出す。係が1体も動いていない状態で頭役が待つと、セッションが止まる
- 終わる時刻か予算の線に来たら、新しい点を出さず、状態ファイルの「経過」と「次にやるなら」を書いてから報告する。持ち主が後で開く場所（状態ファイルのパス、PR、Issue）を報告の頭に書く
