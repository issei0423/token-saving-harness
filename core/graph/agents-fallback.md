# 係の種類が呼べないとき

`graph.md` から切り出した（読む合図：「→ 読む：agents-fallback.md」）

`~/.claude/agents/` の係の種類は、セッションの始めに読み込まれる。入れたばかりのセッションや、種類が一覧に無い環境では呼べない。

- まず、新しいセッションを始められるなら始める（それがいちばん安い）
- 始められないときは `general-purpose` の係を出し、プロンプトの最初に「`~/.claude/agents/<役>.md` を読み、その決まりと返す形に従う」と書く
- 読むだけの役（考える・調べる・照合する）は、プロンプトでも「ファイルを書き換えない、git を操作しない」と念を押す
- 代わりの係は道具が多いぶん重い（作者の実測：`researcher` 29,000 トークンに対して、代わりは 76,134 トークン）。続けて使うなら新しいセッションにする
