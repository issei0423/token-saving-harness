# ~/.claude/CLAUDE.md に足す文

下の囲みの中を、`~/.claude/CLAUDE.md`（どのプロジェクトでも効く、自分の決まり）に足す。足す前に、いまの `CLAUDE.md` を `CLAUDE.md.bak` に写しておく。

```markdown
## トークン節約ハーネス（考える係と実行する係のグラフ）

- **頭役（メインのセッション）**：セッションの始めに `~/.claude/token-harness/core/graph.md` を `Read` で読み、その決まりに従う。「→ 読む」の合図が出た文書だけ開く（全部は読まない）
- **係（サブエージェント。researcher・tester・executor・verifier など）**：`graph.md` は読まない。自分の役の文書と `~/.claude/token-harness/core/graph/worker-rules.md` に従う。考える係（thinker）だけは、点に割るのに要るので `graph.md` を自分で `Read` で開く
```

## `@` で取り込まないわけ

- `@~/.claude/token-harness/core/graph.md` と書くと、核（3,700 字ほど。日本語は 1 字あたり約 0.8 トークンなので、およそ 3,000 トークンの見積もり）が毎セッション丸ごと入る。作者の環境では、この取り込みは係（サブエージェント）にも毎回乗っていた
- 係が要るのは、係に関わる所だけ。それは `worker-rules.md`（約 750 字）と役の文書にある
- 上の形にすると、頭役は `Read` で同じ量を読むので頭役の分は減らないが、係1体ごとの分が減る（見積もり。係の側の実測はまだ）

## 心配なこと

- 頭役が `graph.md` を読み忘れると、決まり（許す操作・予算）が効かない。`@` の取り込みは必ず乗るが、平文の指示は守られないことがある。確実さを取りたい人は `@` に戻す
- 確かめ方：新しいセッションで、頭役が最初の返事の前に `graph.md` を `Read` している。係を1体出すと、`graph.md` を読まずに役の文書と `worker-rules.md` を読んでいる

## 戻し方

`CLAUDE.md.bak` を `CLAUDE.md` に戻す。
