# 仕事の振り分け

役ごとのモデル・道具の正は、係の文書（`core/agents/*.md`）の頭。この文書は、仕事をどの役に回すかだけを書く。

| 仕事の種類 | 役 | 誰が | モデル（既定） | 理由 |
| :-- | :-- | :-- | :-- | :-- |
| 設計・判断・仕分け | think | 頭役か `thinker` | 頭役と同じ | 間違えると後が全部ずれる。ここは節約しない |
| 文書を書く・コードを直す | implement | `executor` | sonnet | 設計が済んでいれば、係で足りる |
| 読むだけの調べもの | research | `researcher` | haiku | 書かないので、小さいモデルと少ない道具で足りる |
| 渡したコマンドを回して数える | test | `tester` | haiku | 判断が要らない |
| 指摘・報告の照合 | verify | `verifier` | sonnet | 原文に当たるだけ。直さない |
| 機械的なコピー | — | 頭役が直接 | — | 渡す説明を書くほうが高くつく（推測） |
| 検証（差分・再実行） | — | 頭役が自分で | — | 係の自己申告を鵜呑みにしない |

## 決めていること

- **考える所は節約しない。** 節約するのは、考えが済んだあとの手
- **係の道具は、役に要るものだけ。** 道具の説明も係の文脈に入るので、道具が多い係は重い（`measure.md` の「代わりの係」）
- **同時は4体まで。** 予算の判断が「小さく」なら2体まで（`core/graph/budget.md`）
- **セッション途中でモデルや effort を切り替えない**（`loading-rules.md`）
- モデルの既定は作者が置いた値。自分の契約と仕事に合わせて、係の文書の `model:` を書き換える
