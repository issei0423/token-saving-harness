# 係への渡し方

## 入れるもの

- 点の id
- やること（目標）
- 終わりの条件
- 許す操作
- 作業場所（ブランチ・worktree。パスは絶対パスで）
- 関係する決定（点に関わるものだけ）

## 入れないもの

- 会話の経緯
- 関係ない文書

## 運び方

- 元の文書は、係の読める場所（作業場所の下）へ写して渡す
- スクラッチパッドは係ごとにフォルダを分ける
- 同じ文書の続きは、新しい係を出さず `SendMessage` で続ける（それまでの文脈を使い回せる）
- 結果は要約で返させる。原文を丸ごと戻さない
- 返ってきた要約は、頭役が差分や再実行で確かめる（`model-routing.md`）

## 例

```
点：R1（調べもの）
やること：このリポジトリで、設定ファイル config.yaml を読んでいる所を全部挙げる
終わりの条件：「ファイル:行 — 何のために読んでいるか」の一覧と、件数
許す操作：読むだけ。ファイルは書き換えない
作業場所：/home/me/work/app（main）
関係する決定：node_modules と .git は見なくてよい
```
