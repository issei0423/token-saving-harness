# 読み込みの決め

## 何がいつ入るか

作者が調べた範囲（2026-10）。出典は第三者の記事が多く、全部は確かめていない。Claude Code の版で変わるので、自分の環境では `/context` で見る。

| 対象 | いつ入るか |
| :-- | :-- |
| `CLAUDE.md` | 常時（起動時） |
| パス指定の無い `.claude/rules/*.md` | 常時（起動時） |
| `@` で取り込んだ文書 | 常時。丸ごと毎回 |
| スキルの説明 | 常時 |
| スキルの本文 | 呼んだとき |
| 係（サブエージェント）の説明 | 常時 |
| 係の本文 | その係を出したとき（係の側に入る） |
| `Read` で開いた文書 | 開いたとき |

## 守ること

- **大きな文書を `@` で取り込まない。** 入口は索引にし、詳細は `Read` かスキルで読む
- **セッション途中で `CLAUDE.md`・モデル・effort を変えない。** 先頭の固定部分のキャッシュが切れる
- スキルと係の説明は短く書く（説明は常時入るため）
- `CLAUDE.md` とスキルで同じことを二重に書かない
- 規則の文書を、圧縮ツールで機械的に縮めない。落とした語が制約だと、静かに動きが変わる
- 常時入る文書には字数の上限を決め、テストで見張る（このリポジトリは核 5,000 字）

## 割り方

1. 常時読む文書を、毎回要る行と、ある場面でだけ要る行に分ける
2. ある場面でだけ要る行は、場面ごとの文書へ移す
3. もとの場所には、1〜3行の要点と「→ 読む：`<文書>`」の合図を残す
4. 落とした文が無いかを確かめる（作者は、もとの文書の空でない行それぞれが、新しい文書のどこかにあるかを照合した）

作者の個人版では、7,857 字の文書を、核 4,944 字と呼ぶとき読む文書 7 つに割った（`measure.md`）。
