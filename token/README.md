# トークン節約の決め

頭役（賢いモデル）には考えることだけをさせ、調べもの・テスト・実装は、役に合わせた係に回してトークンを節約する。その決まりの置き場。

## 索引

- `loading-rules.md`：何が常時入り、何が呼んだときだけ入るか。守ること
- `model-routing.md`：仕事の種類ごとに、どの役・どのモデルに回すか
- `briefing.md`：係に頼むときの渡し方
- `measure.md`：作者の実測の表と、自分で測る手順
- `measure/count_chars.py`：Markdown の文字数・バイト数を数える
- `measure/count_tokens.py`：Markdown のトークン数を、Anthropic の `count_tokens` で数える

## いちばん大事な3つの原則

1. **常時読み込むものを小さくする。** 核（`core/graph.md`）は 5,000 字以内に保つ（`tests/check_docs.py` が毎回見る）
2. **詳しいものは「呼んだときだけ」読む。** 状況ごとの詳細は別の文書へ移し、核には「→ 読む」の合図だけを置く
3. **係に渡す情報は、点に必要なものだけ。** 会話の経緯や関係ない文書は渡さない

## 事実と推測

- 数字は `measure.md` の実測だけを書く。測っていないものは「推測」「見積もり」と書く
- 作者は、測る前に「元の文書は 1 万トークン前後」と見積もっていたが、実測は約 6,400 だった。**測らずに数字を言わない**
